# E-Commerce Sales Performance Analytics Dashboard (2026)

## 📌 Project Overview
This project focuses on auditing and analyzing an e-commerce retail dataset containing over 5,000 global sales transactions. The goal was to clean raw data anomalies, track foundational Key Performance Indicators (KPIs), map seasonal trends, and identify structural revenue drivers for executive decision-making.

## 🛠️ Toolstack Used
* **Python (Pandas):** Automated data cleansing, parsing structural formatting custom layouts, and date normalization.
* **Microsoft Excel:** Data profiling and verification auditing checks.
* **Power BI Desktop:** Implemented a relational data model and engineered an interactive executive reporting interface.

## 📊 Key Business Insights Extracted
* **Financial Total Volume:** Successfully audited a comprehensive sales portfolio generating a net **$5,109,775.74 in total revenue** across **20,224 unit shipments**.
* **Product Domain Champion:** The **Electronics** product segment acts as the prime financial driver, securing the highest market yield margins compared to Clothing or Beauty segments.
* **Logistics Window:** Shipping channels maintain a consistent and reliable operational shipping baseline averaging a **6.1-day delivery turnaround**.
